Implementing Deep Reinforcement Learning on an Inverted pole pendulum on a cart system.
Im using Stable-Baseline3 to call out the PPO algorithm, using MLPpolicy for the neural network

In this project, the STL files a based on my actual hardware; including weights, damping parameters
- m.625 folder is the model's file
- ppo folder is where i train the agent with train.py and test the agent with test.py
